## [Arquitetura](./Arquitetura)
Clean Architecture, DDD, N-Camadas, etc.

## [Infra](./Infra)
Integração com APIs externas, infraestrutura, etc.

## [Persistence Patterns](./Persistence%20Patterns)
Padrões de persistência, repositórios, Unit of Work, etc.

Docker, GitLab/GitHub Actions, buildspec.yml, versionamento, deploys e boas práticas de CI/CD.
