# Referências

Links úteis, livros e ferramentas preferidas. Prefiro poucas fontes boas, lidas até o fim, a uma lista enorme salva para depois.

## Livros

| Livro | Por que ler |
| --- | --- |
| *Designing Data-Intensive Applications*, Martin Kleppmann | o melhor livro sobre sistemas de dados; meu [resumo em português](https://andredarcie.github.io/dive/) |
| *Clean Code*, Robert C. Martin | nomes, funções e testes; leia com senso crítico, parte dos exemplos envelheceu |
| *Domain-Driven Design*, Eric Evans | a origem de DDD; denso, comece pelos capítulos de design estratégico |
| *Implementing Domain-Driven Design*, Vaughn Vernon | DDD com mais código e menos teoria |
| *Refactoring*, Martin Fowler | o catálogo de refatorações seguras |
| *Patterns of Enterprise Application Architecture*, Martin Fowler | Repository, Unit of Work e companhia, na fonte |
| *Fundamentos da Arquitetura de Software*, Mark Richards e Neal Ford | estilos de arquitetura e trade-offs |
| *System Design Interview*, Alex Xu | preparação para a rodada de system design |
| *Release It!*, Michael Nygard | o que acontece com o software em produção: timeouts, circuit breakers, falhas em cascata |

O ranking completo dos livros mais recomendados por desenvolvedores, consolidado de 100 fontes, está em [Best Dev Books](https://andredarcie.github.io/best-dev-books/index.html).

## Documentação e código de referência

- [Documentação do ASP.NET Core](https://learn.microsoft.com/aspnet/core/) e do [EF Core](https://learn.microsoft.com/ef/core/): melhor e mais atualizada do que a maioria dos cursos.
- [eShop](https://github.com/dotnet/eShop): aplicação de referência da Microsoft com microsserviços, .NET Aspire e mensageria.
- [Architecture Guides da Microsoft](https://learn.microsoft.com/dotnet/architecture/): guias gratuitos de microsserviços e arquitetura em .NET.
- [OWASP API Security Top 10](https://owasp.org/API-Security/): os ataques mais comuns em APIs.
- [Martin Fowler](https://martinfowler.com/): o catálogo de padrões e artigos que este guia cita.

## Ferramentas preferidas

| Para | Uso |
| --- | --- |

| Containers | Docker Desktop, .NET Aspire para o ambiente local |
| Logs e traces | Seq local, dashboard do Aspire, Grafana |
